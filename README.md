# 白环纪 · 蚀日之誓

**▶ 立即体验：https://cyzcyz669.github.io/baihuanji/**

一款直接在浏览器里运行的第一人称 3D 动作冒险游戏：五个章节，三位首领，三种结局。

![天眼之环](cover.jpg)

- 推荐用桌面版 Chrome / Edge 打开，并戴上耳机
- 电脑上点击画面锁定鼠标；如果卡顿，可以在「设置」里调低画质
- 手机、平板也能玩：轻触屏幕开始，支持触屏操作，建议横屏。在 Safari 或 Chrome 里用「分享 → 添加到主屏幕」，之后从主屏幕图标打开就没有地址栏了

## 操作

### 键鼠

| 按键 | 作用 | 按键 | 作用 |
|---|---|---|---|
| W A S D | 移动 | 鼠标左键 | 日刃连斩 / 晨星铳射击 |
| Shift | 冲刺 | 鼠标右键 | 格挡（刚好挡住 = 完美格挡）/ 瞄准 |
| 空格 | 跳跃（过场中长按跳过） | 1 / 2 | 切换武器 |
| E（长按） | 互动 | R | 换弹 |
| F | 灯语指路 | Q | 日冕 |
| C | 闪避（贴着攻击闪开 = 完美闪避） | J | 日志 |
| Esc | 暂停 | | |

### 触屏

| 操作 | 作用 | 操作 | 作用 |
|---|---|---|---|
| 左侧拖动 | 移动（摇杆推到外圈冲刺） | 右侧滑动 | 转动视角 |
| 斩 / 射 | 日刃连斩 / 晨星铳射击 | 挡 / 瞄 | 按住格挡 / 点按开关瞄准 |
| 跳 | 跳跃 | 闪 | 闪避 |
| 交互 | 互动（也可直接点提示框） | | |
| 换武 · 换弹 | 切换武器 · 换弹 | 日冕 | 范围震退 |
| 灯语 · 日志 · 暂停 | 屏幕顶部按钮 | 长按屏幕 | 跳过过场 |

### 手柄

支持 Xbox / PlayStation 等标准布局手柄，连接后按任意键即可使用。

| 按键 | 作用 | 按键 | 作用 |
|---|---|---|---|
| 左摇杆 | 移动（按下切换冲刺） | 右摇杆 | 转动视角 |
| RT / R2 | 日刃连斩 / 晨星铳射击 | LT / L2 | 格挡 / 瞄准 |
| A / ✕ | 跳跃（过场中按住跳过） | B / ○ | 闪避 |
| X / □ | 互动（有提示时）/ 换弹 | Y / △ | 切换武器（十字键左 / 右直接选择） |
| RB / R1 | 日冕 | LB / L1、十字键上 | 灯语指路 |
| 视图键 / Share | 日志 | 菜单键 / Options | 暂停 |

菜单里用十字键或左摇杆移动，A 确认、B 返回，左右调节滑块。

## 章节

螺旋之门 · 沙下迷环 · 金顶圣殿 · 云崖白城 · 天眼之环

## 战斗小贴士

- 敌人出手前武器上会闪一下金光：这时按右键格挡，或按 C 闪避（手柄是 LT / B）
- 完美格挡 / 完美闪避后的短时间内，下一刀是「反击」，伤害翻倍
- 蚀灵的虚空弹快打到你时完美格挡，就能把它弹回去，它会追着施法者飞
